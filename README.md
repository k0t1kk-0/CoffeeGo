# CoffeeGo

Мобільний застосунок попереднього замовлення кави для мережі з трьох кав'ярень «CoffeeGo».

**Призначення:** клієнт замовляє й оплачує каву заздалегідь, обирає час отримання та забирає замовлення без черги; бариста бачить чергу онлайн-замовлень своєї кав'ярні, менеджер — замовлення всієї мережі.

**Тип системи:** Mobile (iOS, Android) + Web (панелі бариста і менеджера) + API.

**Статус:** триває Спринт 1 — вхід за телефоном і меню з POS

**Автор:** Котяш Андрій, група ІПЗ-3/1

## Технології

- Backend: C#, ASP.NET Core 8, PostgreSQL 16
- Мобільний застосунок: .NET MAUI (iOS, Android)
- Панелі бариста і менеджера: ASP.NET Core Blazor
- Інтеграції: API POS-системи кав'ярні, платіжний провайдер, push-сповіщення
